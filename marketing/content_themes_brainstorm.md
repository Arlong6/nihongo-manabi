## #1 日劇金句拆解（Drama 主題）

### 商業邏輯
日劇受眾跟動漫迷有重疊但更廣（女性 + 25-45 歲）。觀眾很容易因「我超愛這部劇」而停留、分享、follow。

### 候選作品（台灣人都看過）
- 半澤直樹「倍返しだ！」
- 月薪嬌妻 / 逃避雖可恥但有用「世間体じゃない」
- 我家的故事 / 大豆田永久子
- 派遣女王「私、定時で帰ります」
- 重啓人生「やり直したい」
- 派遣女王主題曲關鍵句
- 100 萬日圓的女人們
- 詐欺遊戲

### 跟動漫差別
- 句子**更貼近日常**（職場、感情、家庭）
- 不是中二語氣，是**社會人語氣**
- 可以拆解 keigo / 敬語

### 法律風險
- ❌ 不能用日劇**畫面或音檔**（版權）
- ✅ 可以用**台詞文字 + 拆解 + 自製動畫**（比照動漫做法）

### 製作成本
- Remotion 模板可以**直接複用 anime 那組**，換 theme（黑/灰質感 vs 紫/金）
- 內容收集成本：3-4 小時跟 GPT 列 20 句

### GPT prompt（要做時用）
```
你是台灣日語學習 IG/TikTok 帳號的內容企劃。請列 20 句「廣為台灣觀眾熟悉的日劇金句」，每句拆成可教學內容。

選句標準：
1. 必須是台灣 70% 以上看日劇的人聽過 / 看過 meme 的
2. 句子 5-15 個音節
3. 必須有可教文法或關鍵詞
4. 偏向職場 / 感情 / 家庭場景（vs 動漫的戰鬥 / 中二）
5. 「倍返しだ！」「世間体じゃない」「私、定時で帰ります」這種 ★

輸出 JSON Array，schema:
[
  {
    "id": "01",
    "drama": "日劇中文名",
    "drama_jp": "日文原名",
    "year": 2013,
    "character": "角色中文名",
    "quote": "台詞日文原文",
    "reading": "假名注音",
    "meaning": "中文翻譯",
    "scene_context": "出現在什麼劇情下 (1 句話)",
    "grammar_point": "教學重點",
    "explanation": "深入解釋 80-120 字",
    "real_use": "現代日本人會在什麼真實情境用 30-60 字",
    "emoji": "1 個 emoji"
  }
]
```

## #2 J-pop 歌詞拆解（Music 主題）

### 商業邏輯
**TikTok 演算法對音樂類流量乘以 3-5 倍**。一句熱門歌詞 + 拆解 = 30 萬觸及不難。

### 候選歌曲
- YOASOBI（夜遊び）— 群青 / 怪物 / アイドル
- King Gnu — Bling-Bang-Bang-Born
- Ado — 唱
- Official髭男dism — Pretender
- 米津玄師 — Lemon / KICK BACK
- AKB48 經典懷舊
- 動漫主題曲（鬼滅、咒術、進擊都行）

### 致命法律問題
**TikTok 上傳含原曲音檔的影片**：
- 個人帳號用 TikTok 內建音樂庫的歌 → 沒問題
- Business 帳號（你之後想切的）→ **不能用 TikTok 音樂庫**（避免商業濫用版權）
- 用原曲音檔 + 商業帳號 = 直接被靜音 / 刪除 / 限流

### 解法 3 選 1
1. **保持個人帳號**，犧牲 Business 數據功能（不影響 Make.com 自動發）
2. **完全不用音檔**，純做歌詞拆解 + 自製旁白（接近動漫模板）
3. 找 **CC0 授權的純樂器 cover** 鋪底（YouTube Audio Library / Pixabay Music）

### 推薦：方案 2
做「歌詞拆解」風格的影片，**完全不放原曲**：
- 模板：YOASOBI 風格的動感字幕 + 中性 BGM
- 內容：「夜にかける」這句到底什麼意思？文法拆解 + 翻譯
- 賺到「想學歌詞」的搜尋流量 + 完全合法

### 製作成本
- 需要新的 Remotion 模板（動感字幕轉場）= 1 天
- 內容收集：1 小時跟 ChatGPT 列 15 句熱門歌詞段落

## #3 日本 vs 台灣文化對比（Compare 主題）

### 商業邏輯
**互動率最高**（留言會炸開「對對對！」）。低製作成本、高傳播力。

### 點子
- 日本人 vs 台灣人在便利商店付錢動作差別
- 電車禮儀（用手機 / 講電話 / 化妝）
- 餐廳結帳：日本不收小費 vs 台灣
- 排隊文化：日本嚴格 vs 台灣彈性
- 道謝方式：日本「すみません」氾濫
- 上下班文化：定時退社 vs 加班

### 製作成本
- 不需要日文音檔，**80% 中文 + 20% 日文關鍵句**
- 用現有 Oops 模板改色系，新主題上線只要 0.5 天

## 我的建議（給未來的自己/Tony）

**等動漫跟踩雷的 TikTok 數據（暖機後一週）**：

- 如果 **動漫 > 踩雷觸及量** → **下一個主題：日劇**（同類受眾）
- 如果 **踩雷 > 動漫觸及量** → **下一個主題：文化對比**（同類痛點）
- 如果**兩個都不溫不火** → **下一個主題：J-pop 歌詞拆解（方案 2）**（最大流量爆發潛力）

不要同時做 3 個新主題 → 內容稀釋、製作成本爆炸、品牌定位模糊。**一次推一個，跑 4-6 週看數據再決定下一個**。

## 共通的內容生產 SOP

每個新主題上線都走這 8 步：
1. 跟 ChatGPT 用 prompt 列 15-20 個 entry
2. 你手動篩到 12-15 個精品
3. 我建 `src/{theme}/data.ts` + scenes + audio gen
4. 第 1 支 render 給你審
5. OK 後批次 render 全部
6. 加進 ROTATION + caption_variants（IG + TT 兩套）
7. enqueue_batch
8. 隔天 01:00 自動接上輪替

每個新主題大約 3-4 小時你的時間 + 3-4 小時我的工程時間。
